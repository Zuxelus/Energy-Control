## 不对应独立方块/卡片类的功能

| 功能 | 上游情况 | 当前状态/本轮优先级 |
|---|---|---|
| 便携屏/物品内部卡槽 | 三分支 ItemPortablePanel、InventoryPortablePanel | Implemented one card + three upgrade slots, held-item locking, live packets, item-component persistence. Both loaders game-tested; full original portable UI differs. |
| 距离升级 | 1.12 ItemUpgrade；现代 ModItems upgrade_range | Implemented 64/128/256/512-block range for 0..3 upgrades. Range check never forces chunks. Both loaders game-tested. |
| 容量/精度升级 | 不宣称与原 range/color/touch/web 升级等价 | New port features: 4/8/12/16 active targets and 0..3 decimal places. Effective behavior game-tested, unit conversions JVM-tested. |
| 全息/扩展屏 | HoloPanel/Extender + 对应渲染器 | Partial: transparent 2x2 and same-type grouping tested; arbitrary thickness/slopes not ported. |
| 完整高级分页/布局/条形图 | PanelSetting、PanelString、IHasBars、GuiAdvancedInfoPanel | 未实现；现有只具多卡行与基本样式 |
| 斜面/厚度/任意旋转 | GuiPanelSlope、原渲染器 | 未实现；仅六面与完整方块 |
| 触摸/切换/网页/WebSocket | ITouchAction、CardToggle、websockets | 未实现；新协议执行需先明确范围 |
| 世界/卡片数据迁移 | 旧 NBT 与 1.21.1 components 不同 | 未实现；不操作用户旧存档 |
| 颜色升级/触摸升级/网页升级 | 原 ModItems/ItemUpgrade | 未实现；当前颜色设置无升级门槛 |
| 合成、传感器套件加工与配方平衡 | kits、KitAssembler、StorageArrayRecipe | 未实现上游工艺；当前简化配方 |

推进顺序：流体单卡 → 能源/流体多目标阵列 → 距离/容量/精度升级 → 便携屏 → 全息/扩展屏 → 可用依赖的专用集成。
